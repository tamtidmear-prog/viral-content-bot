🏗️ Phase 1: Setup — ทำครั้งเดียวจบ

ขั้นตอนนี้ทำแค่ครั้งแรก หลังจากนั้นใช้งานได้เลย (ยกเว้นต่ออายุ token ทุก 60 วัน)

📦 1. สร้าง Facebook App

Facebook App = บัตรผ่านของเราบน API — ทุกครั้งที่เรียก API ต้องบอก Facebook ว่า "เราคือ App นี้" ผ่าน Token ที่ผูกกับ App

1
เปิด Facebook Developer Console

ไปที่ developers.facebook.com/apps/ แล้ว login ด้วย Facebook account ที่เป็น admin ของเพจที่อยากจัดการ

2
กด "Create App"
  • Use case → เลือก "Other"
  • App type → เลือก "Business"
  • ตั้งชื่ออะไรก็ได้ที่จำง่าย เช่น "MyPageBot"
3
จดค่า 2 อย่างนี้ไว้ให้ดี

หลังสร้างเสร็จ ไปที่ Settings → Basic จะเจอ:

  • App ID — เลขประจำตัว App (ไม่ลับ แชร์ได้)
  • App Secret — รหัสลับ (ห้ามแชร์!)
App Secret สำคัญมาก! ใครได้ไป = ทำอะไรก็ได้ในนาม App เรา
เก็บไว้ที่ปลอดภัย ห้ามวางไว้ในโค้ด ห้ามอัพขึ้น GitHub

🔑 2. ขอ Permissions

บอก Facebook ว่า App เราจะทำอะไรบ้าง — ต้องขอก่อนถึงจะใช้ได้

ไปที่ App Dashboard → App Review → Permissions and Features → Request:

Permissionทำอะไรได้จำเป็น?
pages_show_listดูรายชื่อเพจที่เราจัดการ✅ ต้องมี
pages_read_engagementอ่านยอด like, comment✅ ต้องมี
pages_manage_postsสร้าง / แก้ / ลบโพส✅ ต้องมี
pages_manage_engagementตอบ comment, กดไลค์ถ้าต้องการ
เคล็ดลับ: ตอน Generate Token ใน Graph API Explorer (ขั้นตอนถัดไป) จะเลือก permissions ได้อีกที — ไม่ต้องจำว่าขอครบหรือยัง

🟢 3. เปิด Live Mode

ตอนสร้าง App ใหม่ มันจะอยู่ใน "Development Mode" ซึ่ง:

Development 🔴Live 🟢
คนทั่วไปเห็นโพส❌ เห็นแค่ admin ของ App✅ ทุกคนเห็น
เหมาะกับทดสอบใช้งานจริง
1
ไปที่ Settings → Basic

กรอก Privacy Policy URL (จำเป็น) — ถ้าไม่มีเว็บตัวเอง ใช้ Google Docs สร้างหน้า privacy policy ง่ายๆ แล้วเอา link มาใส่ได้

2
เปลี่ยน Toggle เป็น "Live"

ด้านบนของ Dashboard จะมีปุ่ม toggle — กดสลับจาก "In development" → "Live"

ถ้าโพสแล้วคนอื่นไม่เห็น — เช็คตรงนี้ก่อนเลย 90% คือ App ยังเป็น Development Mode อยู่

🎫 4. สร้าง Token

Token = "ตั๋วผ่าน" ที่บอก Facebook ว่าเราเป็นใครและมีสิทธิ์ทำอะไร — มี 4 ประเภท:

ประเภทอายุใช้ทำอะไร
User Token (สั้น) 1-2 ชม.1-2 ชั่วโมงแลกเป็นแบบยาว
User Token (ยาว) 60 วัน60 วันดึง Page Token
Page Token (ชั่วคราว)1-2 ชั่วโมงทดสอบ
Page Token (ถาวร) ไม่หมดอายุไม่หมด!ใช้โพสจริง ✨

เป้าหมายของเรา = ได้ Page Token แบบถาวร ซึ่งต้องทำ 3 ขั้นตอน:

ขั้น 1
ได้ User Token สั้น
→
ขั้น 2
แลกเป็น User Token ยาว
→
ขั้น 3
ดึง Page Token ถาวร ✨

ขั้น 1: ได้ User Token สั้น

1
เปิด Graph API Explorer

ไปที่ developers.facebook.com/tools/explorer/

  • ด้านขวาบน เลือก App ของเรา
  • กด "Add a Permission" → เลือก pages_manage_posts, pages_read_engagement, pages_show_list
  • กด "Generate Access Token"
  • จะมี popup ขอสิทธิ์ → กด "ดำเนินการต่อ" → เลือกเพจทั้งหมดที่อยากจัดการ

ตอนนี้จะได้ User Token สั้น (อายุ 1-2 ชม.) — copy ไว้

ขั้น 2: แลกเป็น User Token ยาว (60 วัน)

2
เรียก Exchange API

เปิด Terminal แล้วรันคำสั่งนี้ (เปลี่ยนค่า 3 จุดที่ highlight):

curl "https://graph.facebook.com/v25.0/oauth/access_token\
  ?grant_type=fb_exchange_token\
  &client_id=ใส่_APP_ID_ตรงนี้\
  &client_secret=ใส่_APP_SECRET_ตรงนี้\
  &fb_exchange_token=ใส่_SHORT_TOKEN_ตรงนี้"

จะได้ response กลับมาแบบนี้:

{
  "access_token": "EAAb...token-ยาวมากกก...",
  "token_type": "bearer",
  "expires_in": 5184000   ← 60 วัน (เป็นวินาที)
}

Copy access_token ไว้ — นี่คือ User Token ยาว

ขั้น 3: ดึง Page Token ถาวร 🎉

3
ดึง Page Token จาก User Token ยาว
# ดึงทุกเพจที่มีสิทธิ์จัดการ
curl "https://graph.facebook.com/v25.0/me/accounts\
  ?fields=name,id,access_token\
  &access_token=ใส่_LONG_USER_TOKEN_ตรงนี้"

Response จะแสดงเพจทั้งหมดพร้อม token:

{
  "data": [
    {
      "name": "ชื่อเพจของเรา",
      "id": "1234567890",
      "access_token": "EAAb...page-token..."
      // ← เก็บ token นี้ไว้! มันไม่หมดอายุ 🎉
    }
  ]
}
ถ้า me/accounts ไม่แสดงเพจบางอัน — ดึงตรงจาก Page ID ได้: 
curl "https://graph.facebook.com/v25.0/PAGE_ID?fields=name,id,access_token&access_token=LONG_TOKEN"

🔒 5. เก็บ Token ให้ปลอดภัย

ได้ Token มาแล้ว — เก็บยังไงให้ปลอดภัย?

✅ วิธีที่ดี

  • เก็บในไฟล์ config ที่ อยู่ใน .gitignore
  • ใช้ password manager (เช่น pass, 1Password, Bitwarden)
  • ใช้ environment variable

❌ ห้ามทำ

  • ห้ามใส่ในโค้ดที่ push ขึ้น GitHub
  • ห้ามส่งผ่านข้อความสาธารณะ
  • ห้ามใส่ใน caption / content ที่จะโพส

ตัวอย่างไฟล์ config แบบง่ายๆ:

// config/my-pages.json (ต้องอยู่ใน .gitignore!)
{
  "pages": {
    "my_page": {
      "id": "ใส่ Page ID",
      "name": "ชื่อเพจ",
      "token": "ใส่ Permanent Page Token"
    }
  }
}

📝 Phase 2: ใช้งาน — โพส / แก้ / ลบ

พร้อมแล้ว! ทุกคำสั่งรันใน Terminal ได้เลย (Mac/Linux/WSL)

💬 6. โพสข้อความ

curl -s -X POST "https://graph.facebook.com/v25.0/PAGE_ID/feed" \
  -d "message=สวัสดีครับ! โพสนี้มาจาก API 🚀" \
  -d "access_token=PAGE_TOKEN"

# สำเร็จจะได้:
{ "id": "PAGE_ID_POST_ID" }   ← เก็บ post_id ไว้ใช้แก้ไข/ลบทีหลัง

📸 7. โพสรูป (ใช้บ่อยสุด!)

curl -s -X POST "https://graph.facebook.com/v25.0/PAGE_ID/photos" \
  -F "message=วันนี้ถ่ายรูปสวยมาฝาก 📸✨" \
  -F "source=@/path/to/image.png" \
  -F "access_token=PAGE_TOKEN"

# สำเร็จจะได้:
{
  "id": "PHOTO_ID",
  "post_id": "PAGE_ID_POST_ID"   ← ใช้อันนี้แก้ไข/ลบ
}
สังเกต: โพสข้อความใช้ -d แต่โพสรูปใช้ -F (เพราะส่งไฟล์) — อย่าสลับกัน!
source=@... ต้องมีเครื่องหมาย @ นำหน้า path ของไฟล์

🖼️ 8. โพสหลายรูป

ต้องทำ 2 ขั้นตอน: upload รูปทีละใบ (ยังไม่โพส) → รวมเป็นโพสเดียว

1
Upload รูปแบบไม่ publish
# รูปที่ 1
curl -s -X POST "https://graph.facebook.com/v25.0/PAGE_ID/photos" \
  -F "source=@image1.png" \
  -F "published=false" \
  -F "access_token=PAGE_TOKEN"
# จดไว้ → {"id": "PHOTO_1_ID"}

# รูปที่ 2
curl -s -X POST "https://graph.facebook.com/v25.0/PAGE_ID/photos" \
  -F "source=@image2.png" \
  -F "published=false" \
  -F "access_token=PAGE_TOKEN"
# จดไว้ → {"id": "PHOTO_2_ID"}
2
รวมรูปเป็นโพสเดียว
curl -s -X POST "https://graph.facebook.com/v25.0/PAGE_ID/feed" \
  -d "message=ภาพถ่ายหลายมุม 📸" \
  -d 'attached_media=[{"media_fbid":"PHOTO_1_ID"},{"media_fbid":"PHOTO_2_ID"}]' \
  -d "access_token=PAGE_TOKEN"

✏️ 9. แก้ไขโพสที่โพสแล้ว

# ใช้ POST /{post_id} — ไม่ใช่ photo_id!
curl -s -X POST "https://graph.facebook.com/v25.0/POST_ID" \
  -d "message=caption ที่แก้แล้ว ✨" \
  -d "access_token=PAGE_TOKEN"

# สำเร็จ: {"success": true}
แก้ได้: caption / ข้อความ
แก้ไม่ได้: รูปภาพ — ถ้าอยากเปลี่ยนรูป ต้องลบโพสเก่าแล้วโพสใหม่

🗑️ 10. ลบโพส

curl -s -X DELETE "https://graph.facebook.com/v25.0/POST_ID\
  ?access_token=PAGE_TOKEN"

# สำเร็จ: {"success": true}
ลบแล้วลบเลย! กู้คืนไม่ได้ — คิดดีๆ ก่อนลบ

🔍 11. ดูข้อมูลโพส

# ดูข้อมูลโพส + permalink
curl -s "https://graph.facebook.com/v25.0/POST_ID\
  ?fields=permalink_url,message,created_time\
  &access_token=PAGE_TOKEN"

# ดู comments
curl -s "https://graph.facebook.com/v25.0/POST_ID/comments\
  ?access_token=PAGE_TOKEN"

# ดูยอด reach / engagement
curl -s "https://graph.facebook.com/v25.0/POST_ID/insights\
  ?metric=post_impressions,post_engaged_users\
  &access_token=PAGE_TOKEN"

🔄 Phase 3: ดูแลระบบ

⏰ 12. ต่ออายุ Token (ทุก 60 วัน)

Page Token ถาวรไม่หมดอายุ — แต่ถ้าต้องดึง token ใหม่ (เช่น เพิ่มเพจ) จะต้อง renew User Token เพราะมันหมดอายุทุก 60 วัน

📋 Checklist ต่ออายุ

  1. ไป Graph API Explorer → เลือก App → Generate Access Token
  2. ได้ Short Token → Exchange เป็น Long Token (ขั้น 2 ในหัวข้อ 4)
  3. ดึง Page Token ใหม่ (ถ้าจำเป็น)
  4. อัพเดตไฟล์ config
แนะนำ: ตั้งปฏิทินเตือนล่วงหน้า 5 วันก่อน token หมดอายุ — จะได้ไม่ลืมแล้วโพสไม่ได้กะทันหัน

➕ 13. เพิ่มเพจใหม่

1
สร้างเพจที่ Facebook

ไปที่ facebook.com/pages/create — API สร้างเพจไม่ได้ ต้องสร้างเองผ่านเว็บ

2
Generate Token ใหม่ที่มีเพจใหม่ด้วย

ไป Graph API Explorer → Generate Token → เลือกเพจใหม่ด้วย

3
ดึง Page Token + เพิ่มใน config

ทำเหมือนขั้นตอนที่ 4 — exchange → ดึง page token → เก็บใน config

🛠️ 14. แก้ปัญหาที่เจอบ่อย

อาการสาเหตุวิธีแก้
Session has expired Token หมดอายุ Generate + exchange token ใหม่
Requires extended permission ไม่ได้ขอ permission Generate token ใหม่ เลือก permissions ให้ครบ
โพสแล้วคนอื่นไม่เห็น App ยังเป็น Dev Mode เปลี่ยนเป็น Live Mode (หัวข้อ 3)
Invalid parameter Format ผิด เช็คว่าโพสรูปใช้ -F ไม่ใช่ -d
Error validating access token Token ไม่ตรงกับ App เช็คว่าใช้ token ของ App ที่ถูกตัว
me/accounts ไม่แสดงเพจ บางเพจไม่ขึ้น ดึงตรงจาก Page ID:
GET /{PAGE_ID}?fields=access_token

💡 เคล็ดลับจากประสบการณ์จริง

  • ใช้ /photos แทน /feed เสมอ — โพสที่มีรูป reach ดีกว่าโพสข้อความเฉยๆ มาก
  • เก็บ post_id ไว้ทุกครั้งที่โพส — จะได้แก้ไข/ลบได้ทีหลัง
  • ทดสอบกับ App ใน Dev Mode ก่อน — พอมั่นใจแล้วค่อยเปลี่ยนเป็น Live
  • Graph API version (เช่น v25.0) อัพเดตทุกปี — เช็ค docs เป็นระยะ
