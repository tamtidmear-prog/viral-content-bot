### หัวข้อหลัก: สัปดาห์ที่โลก AI สั่นสะเทือน — 5 เรื่องใหญ่ที่คุณต้องรู้

### Section 1: Anthropic แซง OpenAI — ระดมทุน $65B
- Anthropic ระดมทุน Series H ได้ $65,000 ล้าน
- มูลค่าบริษัท $965,000 ล้าน → แซง OpenAI ($852B) ครั้งแรก
- ใกล้ IPO — รายได้ปีนี้ $47,000 ล้าน กำลังจะกำไรครั้งแรก
- ผู้ลงทุน: Sequoia, Blackstone, Samsung, Amazon ($5B)

### Section 2: GitHub Copilot เปลี่ยนระบบคิดเงิน
- 1 มิ.ย. 2026 เปลี่ยนจากรายเดือนเหมาจ่าย → คิดตาม token
- Dev โวยหนัก — ค่าใช้จ่ายพุ่ง 10-50 เท่าสำหรับ agentic coding
- Code completion ยังฟรี แต่ agent session คิดเงินตาม token
- บทเรียน: เครื่องมือ AI ฟรี/ถูก อาจแพงขึ้นเมื่อไหร่ก็ได้

### Section 3: Google Gemini 3.5 — Flash มาแล้ว Pro กำลังมา
- Gemini 3.5 Flash เปิดให้ใช้แล้ว — เร็ว 4 เท่า ราคา $1.50/$9 ต่อ 1M tokens
- Flash เก่งกว่า Gemini 3.1 Pro ในงาน coding + agent
- Gemini 3.5 Pro กำลังมาเดือนนี้ — Sundar Pichai พูดเอง
- Deep Think mode สำหรับงานคิดหนัก

### Section 4: CEO DeepMind: AGI อาจมาถึงปี 2029
- Demis Hassabis เลื่อนคำทำนายจาก 5-10 ปี → เร็วสุด 2029
- พูดว่ามนุษย์อยู่ที่ "เชิงเขาของ Singularity" แล้ว
- กังวลว่าสังคมยังไม่เตรียมพร้อม — นักเศรษฐศาสตร์ยังไม่ serious
- AGI = AI ที่เก่งเท่ามนุษย์ในงานคิดหลากหลาย

### Section 5: Agentic AI — ยุคใหม่ที่ AI ลงมือทำงานจริง
- AI Agent ไม่ใช่แค่แชทบอท — ทำงานจริงได้ (ขาย, ซัพพอร์ต, วิจัย, code)
- ทุก cloud platform วาง agent เป็นแกน (AWS, Google, Microsoft, IBM)
- ธุรกิจเล็กก็ใช้ได้ — agent ช่วยลดคนทำงานซ้ำๆ
- นี่คือ software layer ใหม่ของยุคนี้
