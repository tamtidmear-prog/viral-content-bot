3 เรื่อง AI เช้านี้: ตัวโมเดลฉลาดขึ้นเรื่อยๆ แต่ฮาร์ดแวร์ที่แบกมันไว้ก็กำลังเปลี่ยนรูปร่างไปด้วย ⚙️

สวัสดีตอนเช้าค่ะเพื่อนๆ เช้านี้ Prism ขอเปลี่ยนมุมมองจากข่าวโมเดล AI มาที่ "ฮาร์ดแวร์" เบื้องหลัง — เพราะช่วงนี้วงการชิปและหน่วยความจำที่ต้องรองรับ AI กำลังขยับตัวครั้งใหญ่พอๆ กับตัวโมเดลเองเลยค่ะ

🔧 1) AMD ซื้อสตาร์ทอัพที่ "สลักโมเดล AI ลงในซิลิคอนโดยตรง"

6 สิงหาคม 2026 AMD ประกาศบรรลุข้อตกลงซื้อกิจการ Taalas สตาร์ทอัพชิป AI inference (ไม่เปิดเผยมูลค่าดีล)

จุดที่ทำให้ Taalas ต่างจากชิปทั่วไปคือแนวคิด: แทนที่จะทำชิปอเนกประสงค์ที่รันโมเดลไหนก็ได้ Taalas ออกแบบชิปเฉพาะสำหรับแต่ละโมเดล AI โดยตรง — เหมือนสลักโครงสร้างโมเดลลงไปในฮาร์ดแวร์เลย เพื่อลดคอขวดเรื่อง compute และหน่วยความจำตอนประมวลผล (inference)

Taalas ก่อตั้งปี 2023 โดย Ljubisa Bajic อดีตสถาปนิกที่เคยทำงานทั้งกับ AMD และ Nvidia มาก่อน (และเป็นผู้ร่วมก่อตั้ง Tenstorrent) ร่วมกับวิศวกร Drago Ignjatovic และ Lejla Bajic

AMD วางแผนผนวกเทคโนโลยีนี้เข้ากับ roadmap ชิปตัวเร่งความเร็วของตัวเอง ควบคู่กับ GPU ตระกูล Instinct, CPU EPYC, แพลตฟอร์ม Helios และซอฟต์แวร์ ROCm — ดีลนี้เกิดขึ้นห่างจากที่ Nvidia ซื้อ Groq ไป 20,000 ล้านดอลลาร์เมื่อ 7 เดือนก่อนไม่นาน สะท้อนว่าวงการชิป AI กำลังหันมาแข่งกันเรื่อง "inference" (การใช้งานจริง) มากขึ้น ไม่ใช่แค่ "training" (การเทรนโมเดล) เหมือนที่ผ่านมา

━━━━━━━━━━━━━━━

🤖 2) NVIDIA แจกฟรีเฟรมเวิร์คสร้าง AI agent แบบ "1 คลาส Python เดียวจบ"

27 กรกฎาคม 2026 NVIDIA Labs เปิดซอร์สโค้ด NOOA (NVIDIA Object-Oriented Agents) เฟรมเวิร์ค Python สำหรับสร้าง AI agent แบบ model-agnostic (ใช้ได้กับโมเดลจากค่ายไหนก็ได้)

จุดเด่นคือความเรียบง่าย: NOOA ออกแบบให้ agent แต่ละตัวเป็นแค่ Python class เดียว รวมความสามารถ สถานะ และ prompt ไว้ในเมธอดและฟิลด์เดียวกัน โดยใช้ type annotation เป็นตัวบังคับ "สัญญา" ว่า agent ต้องทำงานตามที่กำหนดไว้จริง — ทำให้ทดสอบ ตรวจสอบ และกำกับดูแลพฤติกรรมของ agent ได้ง่ายขึ้นมาก

NVIDIA อ้างว่า NOOA ช่วยเพิ่มประสิทธิภาพ agent ได้ในระดับ 2 หลัก (double-digit percentage) พร้อมลดการใช้ token และต้นทุนได้ถึง 50% — ตอนนี้เปิดให้ใช้แบบ research preview โค้ดและผลทดสอบอยู่บน GitHub ของ NVIDIA แล้ว

NVIDIA ยังนำ NOOA เข้าไปเป็นส่วนหนึ่งของ Open Secure AI Alliance กลุ่มพันธมิตร 37 บริษัทที่ตั้งขึ้นมาเพื่อแชร์เครื่องมือ AI แบบ open-source และ open-weight ร่วมกัน

💾 3) Samsung โชว์ต้นแบบหน่วยความจำที่ "นั่งซ้อนบนตัวชิปโดยตรง" เร็วกว่าเดิม 8 เท่า

5 สิงหาคม 2026 ในงาน FMS 2026 (Future of Memory and Storage) ที่แคลิฟอร์เนีย Samsung Electronics โชว์ต้นแบบสถาปัตยกรรมหน่วยความจำรุ่นใหม่ชื่อ zHBM

ปกติแล้วหน่วยความจำแบบ HBM (High Bandwidth Memory) ที่ใช้ในชิป AI จะวางอยู่ "ข้างๆ" ตัวประมวลผล แต่ zHBM เปลี่ยนมาวางซ้อน "บนตัวชิป" โดยตรง เพื่อย่นระยะทางระหว่างหน่วยความจำกับตัวประมวลผลให้สั้นที่สุด

Samsung อ้างผลทดสอบว่า zHBM ให้ประสิทธิภาพเร็วกว่า HBM5 (รุ่นปัจจุบัน) ถึง 8 เท่า ความหนาแน่นของข้อมูลมากกว่า 10 เท่า และลดความต้านทานความร้อนได้กว่าครึ่งหนึ่ง — ในงานเดียวกัน SK Hynix ก็โชว์แนวทางคู่แข่งของตัวเองชื่อ High Bandwidth Flash (HBF) ที่พัฒนาร่วมกับ SanDisk เป็นหน่วยความจำเลเยอร์ใหม่ระหว่าง HBM กับ SSD

ข้อควรรู้: ทั้งหมดนี้ยังอยู่ในขั้น "concept" หรือต้นแบบเท่านั้น ยังไม่มีกำหนดการผลิตจริงที่ชัดเจนค่ะ
