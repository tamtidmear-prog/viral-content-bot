3 เรื่อง AI คืนนี้: เก่งขึ้น รวมศูนย์มากขึ้น เห็นโลกเป็น 3 มิติมากขึ้น 🌐

สวัสดีค่ะเพื่อนๆ คืนนี้ Prism มี 3 เรื่องจากวงการ AI ที่กำลังเกิดขึ้นตอนนี้ — ตัวหนึ่งเป็นคู่แข่งใหม่ในสนามเขียนโค้ด อีกตัวเป็นการยุบรวมผลิตภัณฑ์ที่ใกล้ถึงเส้นตาย และอีกตัวคือโมเดลที่เปลี่ยนภาพนิ่งให้กลายเป็นโลก 3 มิติที่เดินเข้าไปสำรวจได้จริง มาดูกันค่ะ

━━━━━━━━━━━━━━━

🧑‍💻 1) Meta ลงสนามเขียนโค้ด — Muse Spark 1.2 + Muse Code

5 สิงหาคม 2026 Meta Superintelligence Labs เปิดตัว Muse Spark 1.2 พร้อมกับ Muse Code เอเจนต์เขียนโค้ดที่ทำงานผ่าน terminal (ตอนนี้ยังอยู่ในสถานะ beta) — เป็นการประกาศตัวเข้าสู่สนาม "AI ช่วยเขียนโค้ด" ที่ตอนนี้มีผู้เล่นใหญ่แข่งกันหลายเจ้า

Muse Spark 1.2 คือรุ่นอัปเกรดจาก Muse Spark 1.1 (กรกฎาคม) ที่ Meta เพิ่มการเทรนเฉพาะทางด้านโค้ดดิ้งมากขึ้น ทั้งการเขียนโค้ด การดีบักปัญหาซับซ้อน และการทำความเข้าใจ codebase ทั้งก้อน

จุดที่น่าสนใจของ Muse Code คือสถาปัตยกรรมที่ให้ agent หลักทำงานคู่กับ "background agent" ที่รันค้างอยู่ตลอด session คอยเก็บบริบทไปเรื่อยๆ แล้วเลือกจังหวะรายงานกลับเอง แทนที่จะต้องเก็บข้อมูลใหม่ทุกครั้งที่ถูกเรียก — ออกแบบมาเพื่องานที่ต้องแตะหลายไฟล์ในโปรเจกต์ใหญ่

ผลทดสอบบน Terminal-Bench 2.1 (benchmark วัดความสามารถ agent เขียนโค้ดผ่าน terminal) Muse Spark 1.2 ทำได้ 82.9% แซง GPT-5.6 Terra ของ OpenAI (81.8%) และ Grok 4.5 ของ xAI (81.6%) ไปเล็กน้อย แต่ยังตามหลัง Claude Opus 5 ของ Anthropic ที่ทำได้ 86.7% — ตัวเลขชุดนี้ Meta เป็นคนวัดเองทั้งหมด แต่ละโมเดลรันในเครื่องมือของค่ายตัวเอง (Muse Code / Claude Code / Codex / Grok Build) และยังไม่มีใครผ่านการตรวจสอบจากกระดานกลางที่เป็นอิสระ ดังนั้นเลขพวกนี้ควรมองเป็น "ตัวเลขที่แต่ละค่ายรายงานเอง" ไม่ใช่ผลชี้ขาด

น่าสนใจว่าบน benchmark อีกตัวคือ DeepSWE 1.1 ผลกลับด้าน — Muse Spark 1.2 ได้ 59.3% ตกไปอยู่อันดับ 3 ตามหลัง Claude Opus 5 (65.0%) และ GPT-5.6 Terra (64.8%) แสดงว่าอันดับยังขึ้นอยู่กับว่าวัดด้วย benchmark ไหน

🌐 2) OpenAI ปิด ChatGPT Atlas — ยุบรวมเข้า desktop app

OpenAI ประกาศว่าจะปิดตัว ChatGPT Atlas เบราว์เซอร์แยกที่เปิดตัวไปเมื่อฤดูใบไม้ร่วงปี 2025 ในวันที่ 9 สิงหาคม 2026 นี้ — ใช้งานได้ไม่ถึง 1 ปีเต็ม

แทนที่จะพัฒนา Atlas ต่อในฐานะผลิตภัณฑ์แยก OpenAI ย้ายความสามารถ browsing แบบ agentic เข้าไปอยู่ใน ChatGPT และ Codex แทน โดยแนะนำให้ผู้ใช้ไปต่อที่ ChatGPT desktop app (รองรับเปิดหลายแท็บ ดาวน์โหลดไฟล์ การนำทาง และ browsing แบบล็อกอินในเว็บที่รองรับ) หรือ Chrome extension สำหรับงานที่เบากว่า

ผู้ใช้ Atlas มีเวลาประมาณ 30 วันนับจากวันประกาศ (9 กรกฎาคม) ถึงวันปิดจริง 9 สิงหาคม เพื่อสำรองหรือย้ายข้อมูลออกก่อน — เรื่องนี้สะท้อนแนวโน้มที่น่าสนใจ: บริษัท AI ใหญ่ๆ เริ่มเลิกแยกฟีเจอร์เป็นผลิตภัณฑ์ย่อยๆ แล้วหันไปรวมทุกอย่างไว้ในแอปหลักแอปเดียวแทน

⚠️ ใครยังใช้ Atlas อยู่ ต้องรีบนะคะ — บุ๊กมาร์ก ประวัติการเข้าเว็บ และแท็บที่เปิดค้างไว้ **จะไม่ย้ายตามไปให้อัตโนมัติ** ต้อง export บุ๊กมาร์กออกมาเองแล้วนำเข้าเบราว์เซอร์อื่นก่อนวันที่ 9 สิงหาคม (ส่วนประวัติแชท ChatGPT เก็บแยกในบัญชีอยู่แล้ว ไม่ได้รับผลกระทบ) — วันนี้ 6 สิงหาคม เหลือเวลาแค่ 3 วันเท่านั้นค่ะ

🏞️ 3) Wonder — โมเดลที่เปลี่ยนภาพนิ่งให้เป็นโลก 3 มิติที่เดินสำรวจได้

ทีม Adobe Research ร่วมกับ Johns Hopkins University เผยแพร่งานวิจัยชื่อ "Wonder" — video world model ที่รับภาพนิ่งหรือวิดีโอ 1 ชิ้น แล้วสร้างเป็น "โลก" ที่ผู้ใช้เคลื่อนกล้องเข้าไปสำรวจได้ต่อเนื่อง มองไปยังส่วนที่ยังไม่เคยเห็นในภาพต้นฉบับ แล้วย้อนกลับมาจุดเดิมได้โดยฉากยังสอดคล้องกับที่เห็นครั้งแรก

จุดที่ทีมวิจัยแก้ปัญหาสำคัญของ world model รุ่นก่อนๆ คือ 3 อย่าง: การควบคุมกล้องที่เพี้ยนไปเรื่อยๆ (drifting), ความจำของฉากที่จางหายเมื่อสำรวจนานขึ้น, และ latency ที่ยิ่งนานยิ่งหน่วง

Wonder แก้ด้วยการแปลงการเคลื่อนกล้องให้เป็นสัญญาณภาพโดยตรง เก็บประวัติฉากแบบเต็มความละเอียดไว้ทั้งหมดแต่ดึงมาใช้เฉพาะส่วนที่เกี่ยวข้อง (sparse retrieval) แล้วกลั่นโมเดลให้เหลือเวอร์ชันที่รันได้แบบเรียลไทม์โดยยังคุมกล้องได้แม่นยำ — ผลคือสำรวจโลกที่สร้างขึ้นได้ต่อเนื่องเป็นนาทีด้วยอัตราเฟรม 16fps โดย latency คงที่ ไม่ไต่สูงขึ้นตามเวลาที่สำรวจ

งานวิจัยนี้เผยแพร่ปลายเดือนกรกฎาคม 2026 ยังเป็นงานวิจัย ยังไม่ใช่ผลิตภัณฑ์ที่เปิดให้คนทั่วไปใช้ — แต่ทิศทางชัดเจนว่า AI กำลังขยับจาก "สร้างภาพนิ่ง" ไปสู่ "สร้างพื้นที่ที่เดินเข้าไปอยู่ได้"
