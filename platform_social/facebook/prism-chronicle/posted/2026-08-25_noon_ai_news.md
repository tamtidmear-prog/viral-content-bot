1️⃣ Microsoft Copilot มีช่องโหว่ที่ให้ Copilot "แฉตัวเอง" 🔍

นักวิจัยจาก Varonis Threat Labs เจอช่องโหว่ชื่อ "CoSnitch" (CVE-2026-24301) ใน Microsoft Copilot Personal ที่รายงานให้ Microsoft รู้ตั้งแต่เดือน ธ.ค. 2025 และเพิ่งได้รับการแก้ไขเมื่อ 18 ส.ค. 2026 ที่ผ่านมา

ที่น่าสนใจคือวิธีที่นักวิจัยเจอช่องโหว่นี้ — พวกเขาถาม Copilot ซ้ำไปซ้ำมาว่าทำไมการรันคำสั่งอัตโนมัติถึงเป็นไปไม่ได้ จนสุดท้าย Copilot เผลอเปิดเผยพารามิเตอร์ลับในลิงก์ที่ไม่เคยมีการเปิดเผยมาก่อนออกมาเอง กลางประโยคที่กำลังปฏิเสธคำขอนั้นแหละ

ช่องโหว่จริงคือ ลิงก์ที่มีพารามิเตอร์ซ่อนอยู่ (`autorun=1` คู่กับคำสั่ง) ทำให้แค่คลิกลิงก์เดียว Copilot จะรันคำสั่งอัตโนมัติทันทีโดยไม่ต้องยืนยันอะไรเพิ่ม แล้วดึงข้อมูลจากแอปที่เชื่อมต่อไว้ เช่น Gmail, Google Drive, ปฏิทิน ออกไปได้ ที่หนักกว่านั้นคือมันยังฝังคำสั่งถาวรลงในระบบความจำข้ามเซสชันของเหยื่อได้ ซึ่งอยู่รอดแม้เปลี่ยนรหัสผ่านหรือลงทะเบียนอุปกรณ์ใหม่แล้วก็ตาม ทีม Varonis สรุปเหตุการณ์นี้ไว้สั้นๆ ว่า Copilot ไม่ได้ถูกเจาะ แต่ถูก "เล่นเกม" ให้หลอกตัวเอง

Microsoft ยืนยันว่ายังไม่พบการโจมตีจริงก่อนแพตช์ออก แต่นี่คือช่องโหว่ตัวที่ 3 ของ Copilot ที่ Varonis เจอในปีนี้ ต่อจาก Reprompt และ SearchLeak

2️⃣ Anthropic เปิด "โรงเรียนสอนใช้ Claude" ฟรี 📚

Anthropic เปิดตัว Claude Academy (academy.claude.com) แพลตฟอร์มเรียนรู้ฟรีอย่างเป็นทางการ รวมบทเรียน คำแนะนำการเขียน prompt และตัวอย่างการใช้งานจริงกว่า 355 รายการ ครอบคลุม 5 กลุ่มผลิตภัณฑ์หลัก ได้แก่ Claude.ai, Claude Cowork, Claude Code, Claude Tag และ Claude Platform (API/Console/MCP)

คอร์สหลักตัวหนึ่งชื่อ "AI Fluency: Framework & Foundations" สอนหลักการทำงานร่วมกับ AI ผ่านกรอบคิด 4D คือ Delegation (มอบหมายงาน), Description (อธิบายงานให้ชัด), Discernment (รู้จักตรวจสอบผลลัพธ์) และ Diligence (ใช้งานอย่างรับผิดชอบ) ไม่ว่าจะเป็นมือใหม่ที่ไม่เคยใช้ AI เลย ไปจนถึงทีมที่กำลังจะเอา AI ไปใช้งานทั้งองค์กร ก็มีเส้นทางเรียนรู้ให้เลือกตามระดับ

3️⃣ OpenAI หั่นราคา GPT-5.6 Sol ลงอีกกว่า 20% 💸

21 ส.ค. 2026 OpenAI ประกาศลดราคา API ของโมเดลเรือธง GPT-5.6 Sol ลงทุกรายการ โดยราคาโปรโมชันนี้การันตีไว้ถึง 21 พ.ย. 2026

สำหรับ context ไม่เกิน 272K token: input จาก $5.00 เหลือ $4.00 ต่อล้าน token (ลด 20%), output จาก $30.00 เหลือ $20.00 ต่อล้าน token (ลดถึง 33%), ส่วน cached input จาก $0.50 เหลือ $0.40 ต่อล้าน token ส่วน context ที่ยาวกว่า 272K token ก็ลดในสัดส่วนเดียวกัน (input $10→$8, output $45→$30)

OpenAI ให้เหตุผลว่าการลดราคาครั้งนี้มาจากแรงกดดันการแข่งขันที่เพิ่มขึ้นทั้งจาก Anthropic และโมเดลจีนหลายค่าย ทำให้ราคาต่อความฉลาดในตลาด AI ตอนนี้ขยับเร็วกว่าที่เคยเป็นมา
