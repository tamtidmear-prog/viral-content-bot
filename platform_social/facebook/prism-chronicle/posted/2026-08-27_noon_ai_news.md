🧠 เคยไหมคะ ที่ต้องอธิบายเรื่องเดิมให้ AI ฟังซ้ำทุกครั้งที่เปิดแชทใหม่ — ชื่อโปรเจกต์ สไตล์การเขียนที่ชอบ หรือบริบทงานที่ทำอยู่

วันนี้พาไปเทียบฟีเจอร์ "จำเราได้ข้ามแชท" ของ 3 AI ตัวหลัก — Claude, ChatGPT, Gemini ว่าใครจำอะไร จำยังไง ค่ะ (แถมข่าวอัปเดตล่าสุดของ Claude ที่เพิ่งเปลี่ยนเมื่อ 2 วันก่อนด้วย)

━━━━━━━━━━━━━━━━━━━

🟣 Claude — Memory (เพิ่งเปิดให้ผู้ใช้ฟรีแบบอัตโนมัติแล้ว)

Claude เปิดฟีเจอร์ Memory ครั้งแรก 11 กันยายน 2025 ให้แพลน Team/Enterprise ก่อน แล้วขยายมาแพลน Pro/Max วันที่ 23 ตุลาคม 2025 — ตอนนั้นผู้ใช้ฟรียังไม่มีสิทธิ์เข้าถึงเลย

แต่ 2 มีนาคม 2026 Anthropic ขยาย Memory (แบบดึงจากประวัติแชทเก่า) ให้ผู้ใช้ทุกแพลนรวมถึงฟรีด้วย และล่าสุด 25 สิงหาคม 2026 — เพิ่งผ่านมาแค่ 2 วัน — เปลี่ยนสถานะจาก "ต้องเปิดเอง" เป็น "เปิดให้อัตโนมัติ" (on by default) สำหรับแพลนฟรี/Pro/Max ส่วนแพลน Team/Enterprise ยังปิดไว้เป็นค่าเริ่มต้น (องค์กรต้องเปิดเอง)

**วิธีทำงาน:** Claude เก็บข้อมูลจากบทสนทนาให้อัตโนมัติ แยกเป็น "memory entries" ตามหัวข้อ ดูและแก้ไขได้ตลอด (อัปเดต 10 กรกฎาคม 2026 เปลี่ยนจากสรุปรายวันมาเป็นรายการแยกหัวข้อแบบนี้) และตั้งแต่ 25 สิงหาคมยังเลือก "กันหัวข้ออ่อนไหว" เช่น สุขภาพ ความเชื่อ ไม่ให้เข้า memory ได้ด้วย เว้นแต่จะเปิดอนุญาตเอง

**จุดเด่นที่ AI ตัวอื่นไม่มี:** ถ้าใช้ฟีเจอร์ Projects ด้วย Claude จะแยก memory เป็นรายโปรเจกต์ให้อัตโนมัติ — งานของโปรเจกต์หนึ่งจะไม่ไปปนกับอีกโปรเจกต์

**ถ้าไม่อยากให้จำ:** มี Incognito Chat (คุยแบบไม่บันทึกอะไรเลย ไม่ขึ้นในประวัติ) ให้ทุกแพลนใช้ได้ฟรี

━━━━━━━━━━━━━━━━━━━

🟢 ChatGPT — Memory (ฟรีก็ใช้ได้มาตั้งแต่ปีก่อน)

ChatGPT เปิดให้ผู้ใช้ฟรีเข้าถึง Memory แบบเบาตั้งแต่ 3 มิถุนายน 2025 — มาก่อน Claude เกือบปี

**วิธีทำงาน:** แบ่งเป็น 2 ส่วน — "saved memories" (รายละเอียดที่ขอให้จำตรงๆ เช่น ชื่อ สีที่ชอบ ข้อจำกัดอาหาร) กับ "chat history" (ดึงข้อมูลจากแชทเก่ามาปรับคำตอบให้เข้ากับเรามากขึ้น) เปิด-ปิดแยกกันได้ที่ Settings → Personalization → Memory

**ความต่างตามแพลน:** ผู้ใช้ฟรีจำได้แค่ระยะสั้น ส่วนผู้ใช้ Plus/Pro จำได้ลึกและนานกว่า — และตั้งแต่มิถุนายน 2026 OpenAI เริ่มทยอยเปิดระบบใหม่ชื่อ "Dreaming" ให้ ChatGPT อ่านย้อนบทสนทนาเก่าเป็นพักๆ แล้วปรับปรุงสิ่งที่จำเกี่ยวกับเราเองอัตโนมัติโดยไม่ต้องสั่ง (เริ่มจาก Plus/Pro ในสหรัฐฯ ก่อน ยังไม่ครอบคลุมทุกประเทศ)

━━━━━━━━━━━━━━━━━━━

🔵 Gemini — Personal Intelligence (เชื่อมแอป Google ได้ลึกสุด แต่ยังเบต้า)

Gemini เปิดตัว Personal Intelligence เป็นเวอร์ชันเบต้า 14 มกราคม 2026 — เรียนรู้จากแชทเก่า บวกเชื่อมข้อมูลจาก Gmail, Photos, Search, YouTube เพื่อให้คำตอบเข้ากับเรามากขึ้น เช่น ช่วยวางแผนทริปต่อจากที่เคยคุยไว้ หรืออัปเดตความคืบหน้าโปรเจกต์

**เงื่อนไขที่ต้องรู้:** ต้องอายุ 18 ปีขึ้นไป ใช้บัญชี Google ส่วนตัว (บัญชีที่ทำงาน/โรงเรียนใช้ไม่ได้) และตอนนี้ยังไม่เปิดให้ผู้ใช้ในเขต EEA, สวิตเซอร์แลนด์, สหราชอาณาจักร, ไนจีเรีย

**วิธีเปิด-ปิด:** เลือกได้เองว่าจะเชื่อมแอปไหนบ้าง ปรับได้ทุกเมื่อ ใช้งานได้ทั้งเว็บ Android iOS — เป็นฟีเจอร์ optional ไม่ได้บังคับเปิด

📊 สรุปเทียบไว จำง่าย (อัปเดตหลังข่าว 25 ส.ค.)

**อยากได้ memory ติดตัวแบบไม่ต้องเปิดเอง (on by default)** → ตอนนี้ Claude ก็ทำแบบนี้แล้วสำหรับผู้ใช้ฟรีด้วย ไม่ใช่จุดต่างของ ChatGPT อีกต่อไป
**อยากได้ memory แยกตามโปรเจกต์อัตโนมัติ** → Claude ทำได้ดีสุด (แยกให้เองเมื่อใช้ Projects)
**อยากได้ personalization ที่ลึกถึงข้อมูลแอปอื่นของตัวเอง (เมล/รูป/ประวัติค้นหา)** → Gemini ไปไกลสุด แต่ยังเป็นเบต้าจำกัดพื้นที่ใช้งาน
**อยากคุยแบบไม่ให้จำอะไรเลยชั่วคราว** → Claude มี Incognito Chat ให้ทุกแพลนฟรี

💡 เคล็ดลับใช้จริง: ไม่ว่าจะใช้ตัวไหน ลองเข้าไปดู memory summary ของตัวเองสักครั้ง — บางทีมีข้อมูลเก่าที่ไม่ตรงกับตอนนี้แล้วติดค้างอยู่ (เช่น โปรเจกต์ที่เลิกทำไปแล้ว) แก้ไขให้ตรงปัจจุบันจะได้คำตอบที่ตรงใจมากขึ้นค่ะ ทั้งสามเจ้าเพิ่งอัปเดตฟีเจอร์นี้กันคึกคักมากในปีนี้ — ถ้าลองใช้มาสักพักแล้วรู้สึกว่า "จำผิดๆ" ลองเข้าไปเช็ค settings ดูใหม่อีกครั้ง อาจมีของใหม่ที่ยังไม่เคยรู้ค่ะ
