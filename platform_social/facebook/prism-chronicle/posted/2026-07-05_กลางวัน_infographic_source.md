# Prism Chronicle — Infographic Source (กลางวัน 2026-07-05)

## Mascot (บังคับทุกภาพ)
Prism mascot = คริสตัลปริซึม (crystal prism) kawaii สไตล์ สีรุ้ง (rainbow gradient), มีตาโตน่ารักแบบ chibi, ยิ้ม, ลอยอยู่กลางแสงที่หักเหเป็นสีรุ้ง — ต้องปรากฏในภาพนี้ชัดเจน ห้ามวาดเป็นหุ่นยนต์/นักบินอวกาศ/ตัวการ์ตูนอื่น

## หัวข้อโพส: How-To — NotebookLM คืออะไร ใช้ยังไงให้ได้ประโยชน์สุด
Pillar: 3 (How-To)

## 5 ประเด็นหลักสำหรับ infographic (ต้องตรงกับ draft เป๊ะ)
1. NotebookLM = AI Research Assistant จาก Google ฟรี ตอบจากเอกสารที่อัปโหลดเท่านั้น (ลด hallucination)
2. อัปโหลดได้หลายชนิด: PDF, Word, Google Docs/Slides, เว็บลิงก์, YouTube — สูงสุด 50 แหล่งข้อมูล/โปรเจกต์ (แผนฟรี)
3. Audio Overview: แปลงเอกสารเป็นพอดแคสต์ AI 2 คนคุยกัน เลือกได้ Deep Dive / Brief / Critique / Debate + Interactive Mode พิมพ์คำถามแทรกระหว่างฟังได้ (เป็นการพิมพ์ ไม่ใช่พูด)
4. Studio Features อื่น: Mind Map, Flashcards, Slide Deck outline
5. ใครควรใช้: นักเรียน/นักศึกษา, คนวัยทำงานสรุปรายงาน, นักวิจัย/content creator

## Step-by-step (5 ขั้น) สำหรับ how-to visual
1. เข้า notebooklm.google.com ล็อกอิน Google ฟรี
2. New Notebook
3. อัปโหลด Sources (PDF/ลิงก์/Drive)
4. พิมพ์ถามคำถามในแชท
5. กด Generate ที่ Audio Overview (Studio panel) รอ 2-5 นาที ได้พอดแคสต์
