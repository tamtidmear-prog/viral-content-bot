# Infographic Source — กลางวัน (Pillar 2: วิธีคิด)

Prism mascot: ตัวคริสตัลรูปเพชรน่ารัก kawaii สีรุ้งพาสเทล หน้ายิ้ม แขนขาเล็กๆ ชื่อ Prism — ใช้ mascot นี้เป็นตัวเล่าเรื่องหลักในทุก section ของ infographic

## หัวข้อ
5 ระดับความน่าเชื่อถือของ "สัญญาณว่าเสร็จแล้ว" — จากอ่อนสุดไปแน่นสุด

1. ไม่มีเสียงบ่น / ไม่มี error (อ่อนสุด — เงียบได้ทั้งที่จริงพัง)
2. ป้าย/สถานะบอกว่าโอเค (ป้ายโอเคได้แม้เนื้อในว่างเปล่า)
3. หน้าตา/รูปแบบถูกต้อง (รูปแบบถูกแต่เนื้อหาข้างในผิดได้)
4. เนื้อในตรงกับความจริง — อ่านเนื้อหาจริงแล้วเทียบ
5. ลองใช้งานจริงแล้วได้ผลจริง (แน่นสุด)

## แนวคิดหลัก
ก่อนเชื่อว่า "เสร็จแล้ว" ให้เลือกตรวจที่ layer สูงสุดเท่าที่ทำได้ ไม่ใช่เชื่อ layer แรกที่เจอ เพราะ layer ต่ำมักถูกทำให้ "ผ่าน" ได้ทั้งที่ของจริงยังไม่เสร็จ

## ตัวอย่างประกอบ (ใช้ในภาพได้)
- ลิงก์เว็บที่กดแล้วขึ้นหน้าเว็บ (status โอเค) แต่จริงๆ เป็นหน้า error ที่แต่งหน้าตาให้ดูปกติ
- ใบเสร็จ/สลิปโอนเงิน/หลักฐานส่งของ = ระดับ 2 (แค่บอกว่ากระบวนการจบแล้ว) ≠ ของถึงมือคนรับจริง = ระดับ 5 — ห้ามระบุว่าใบเสร็จ/สลิปเป็นระดับ 3 เด็ดขาด
- checklist ที่ไม่มีอะไรให้เช็คเลย (0 จาก 0 ข้อ) ก็ยัง "ผ่าน" ได้ แต่ไม่มีความหมายอะไรเลย — ต้องมีของให้ตรวจจริง ตัวเลข >0 ก่อนถึงจะเรียกว่าตรวจแล้ว

## ข้อห้ามเชิงถ้อยคำ (กัน generator สรุปผิด)
- ห้ามระบุจำนวนระดับเป็นอย่างอื่นนอกจาก 5 ระดับ
- ห้ามเขียนว่า "เชื่อได้ทันที" ที่ระดับ 1-3 — ทั้ง 3 ระดับนี้คือ "ยังไม่พอเชื่อ" ไม่ใช่ "เชื่อได้"
- ห้ามใช้ตัวเลข/สถิติที่ไม่มีในนี้ (ห้ามเดาเปอร์เซ็นต์ ห้ามอ้างงานวิจัยที่ไม่ได้ระบุ)
- **ห้ามวางไอคอน "สลิปโอนเงิน/ใบเสร็จ" ไว้ในกลุ่มเดียวกับระดับ 4-5 (กลุ่ม "มั่นใจได้จริง") เด็ดขาด** — สลิป/ใบเสร็จต้องอยู่ในกลุ่มระดับ 1-3 ("ยังเชื่อถือไม่ได้") เท่านั้น เพราะสลิปคือแค่หลักฐานว่ากระบวนการจบ (ระดับ 2) ไม่ใช่หลักฐานว่าของถึงมือจริง
- ถ้าจะเปรียบเทียบ "สลิป ≠ ของถึงมือจริง" ให้วางไอคอนสลิปในฝั่งกลุ่มระดับ 1-3 และวางไอคอน "พัสดุ/ของถึงบ้านแล้วมีคนมารับ" ไว้ในฝั่งกลุ่มระดับ 4-5 เท่านั้น ห้ามวางทั้งคู่ไว้ด้วยกันในกลุ่มเดียว
