🌐 Prism Chronicle — How-To: AI Browser Agent คืออะไร ใช้ยังไงให้ปลอดภัย

สวัสดีค่ะทุกคน ช่วงนี้เบราว์เซอร์ที่มี "AI ช่วยเล่นแทนเรา" (คลิกปุ่ม กรอกฟอร์ม เปิดแท็บใหม่ ทำงานต่อเนื่องให้เอง) กำลังกลายเป็นเรื่องปกติมากขึ้นเรื่อยๆ ค่ะ วันนี้ Prism พาไปรู้จัก 3 เจ้าใหญ่ที่คนพูดถึงมากที่สุด พร้อมสรุปวิธีใช้ให้ปลอดภัยแบบเข้าใจง่าย

🤖 **AI Browser Agent คืออะไร**

ปกติเวลาเราคุยกับ AI แบบ ChatGPT หรือ Claude มันจะ "ตอบ" อย่างเดียว แต่ AI Browser Agent คือ AI ที่ "ลงมือทำ" ในเบราว์เซอร์แทนเราได้จริงๆ — อ่านหน้าเว็บ คลิกลิงก์ พิมพ์ข้อความลงฟอร์ม สลับแท็บ ไปจนถึงทำงานหลายขั้นตอนต่อเนื่อง เช่น ค้นของ เปรียบเทียบราคา แล้วกดสั่งซื้อให้เสร็จ

ฟังดูสะดวกมาก แต่จุดที่ต้องระวังคือ AI ตัวนี้ "ทำงานในเซสชันที่เราล็อกอินอยู่" ถ้ามีใครแอบซ่อนคำสั่งอันตรายไว้ในหน้าเว็บที่เราเข้า (เรียกว่า prompt injection) AI อาจถูกหลอกให้ทำสิ่งที่เราไม่ได้ตั้งใจ เช่น ดึงข้อมูลส่วนตัวออกไปโดยไม่รู้ตัว

━━━━━━━━━━━━━━━━━━━

🟣 **Claude in Chrome (Anthropic)**

ส่วนขยาย Chrome ที่ให้ Claude อ่านหน้าเว็บ คลิก พิมพ์ กรอกฟอร์ม และสลับหน้าแทนเราได้ เปิดให้ใช้งานจริงกับผู้ใช้แผนเสียเงินทุกแผนตั้งแต่ 26 ส.ค. 2026 ค่ะ

จุดที่ Anthropic ให้ความสำคัญมากคือการป้องกัน prompt injection — มี "safety classifier" ตรวจทุกคำสั่งก่อนอนุมัติอัตโนมัติว่าตรงกับสิ่งที่เราขอจริงไหม และมี "probe" คอยสแกนเนื้อหาที่ AI อ่านมาก่อนที่จะลงมือทำ เพื่อจับคำสั่งแปลกปลอมที่ซ่อนอยู่ในหน้าเว็บ

ตัวเลขที่ Anthropic เปิดเผยเอง (ทดสอบภายในด้วยทีม red-team จำลองการโจมตี, เปิดระบบป้องกันเต็มรูปแบบ): รุ่นใหม่อย่าง Sonnet 5 และ Opus 5 ป้องกันได้ 100% (โดนแฮ็กสำเร็จ 0%) ส่วน Fable 5 อยู่ที่ 0.3% เทียบกับรุ่นเก่าอย่าง Opus 4.5 ที่เคยโดนสำเร็จถึง 16.7% — คือดีขึ้นชัดเจนตามรุ่น แต่ Anthropic เองก็ยอมรับตรงๆ ว่า "ไม่มี browser agent ตัวไหนปลอดภัย 100% จาก prompt injection"

🟢 **ChatGPT Atlas (OpenAI) — ปิดตัวไปแล้ว**

ถ้าใครเคยได้ยินชื่อ "ChatGPT Atlas" เบราว์เซอร์แยกของ OpenAI เองต้องอัปเดตค่ะ — OpenAI ประกาศเลิกให้บริการ Atlas ไปตั้งแต่วันที่ 9 ส.ค. 2026 ใช้เวลาไม่ถึง 10 เดือนนับจากเปิดตัว โดยย้ายความสามารถ "ใช้เบราว์เซอร์แทนเรา" (agentic browsing) เข้าไปรวมกับแอป ChatGPT หลักและ Codex แทน ไม่ได้เป็นเบราว์เซอร์แยกอีกต่อไป

ใครที่เคยใช้ Atlas เก็บ bookmark หรือประวัติการเข้าเว็บไว้ ต้องส่งออกข้อมูลเองก่อนปิดระบบ เพราะข้อมูลไม่ได้ย้ายให้อัตโนมัติ ตอนนี้ถ้าอยากได้ฟีเจอร์แบบเดียวกันต้องไปใช้ผ่านแอป ChatGPT ปกติแทนค่ะ

🔵 **Perplexity Comet — ยังใช้งานอยู่ แต่มีคดีความและช่องโหว่ที่ควรรู้**

Comet ของ Perplexity ยังเปิดให้ใช้อยู่ปกติ จุดเด่นคือช่วยช้อปปิ้งออนไลน์ เปรียบเทียบราคา สั่งซื้อแทนเราได้ แต่มี 2 เรื่องที่ Prism คิดว่าคนทั่วไปควรรู้ก่อนใช้:

1) **ช่องโหว่ "CometJacking"** — นักวิจัยด้านความปลอดภัย LayerX แจ้ง Perplexity แบบ responsible disclosure ตั้งแต่ 27 ส.ค. 2025 แล้วเผยแพร่ต่อสาธารณะ 4 ต.ค. 2025 ว่าแค่คลิกลิงก์ที่มีคำสั่งซ่อนอยู่ใน URL ก็อาจทำให้ Comet ถูกหลอกให้ส่งข้อมูลออกไปได้ ตอนแรก Perplexity ตอบว่าตรวจแล้ว "ไม่พบผลกระทบด้านความปลอดภัย" (not applicable)

2) **คดีความกับ Amazon** — Amazon ฟ้อง Perplexity ว่า Comet เข้าถึงบัญชี Amazon ที่มีรหัสผ่านของผู้ใช้โดยไม่ได้รับอนุญาตจาก Amazon (แม้ผู้ใช้จะอนุญาตเองก็ตาม) ศาลรัฐบาลกลางสหรัฐฯ เคยสั่งห้ามชั่วคราว (preliminary injunction) เมื่อประมาณ มี.ค. 2026 แต่ล่าสุดศาลอุทธรณ์ (Ninth Circuit) กลับคำสั่งนั้นเมื่อ 4 ส.ค. 2026 ทำให้ Perplexity กลับมาใช้ฟีเจอร์ช้อปปิ้งบน Amazon ได้ต่อระหว่างที่คดีหลักยังไม่จบ — เรื่องนี้สะท้อนว่ากฎหมายเรื่อง "AI agent เข้าบัญชีเราแทนเรา" ยังไม่นิ่ง เปลี่ยนได้ตลอด

✅ **ใช้ AI Browser Agent ให้ปลอดภัย — 5 ข้อจำง่ายๆ**

1. **เปิดเฉพาะตอนใช้จริง** — อย่าปล่อย agent mode ทำงานทิ้งไว้เบื้องหลังตลอดเวลา
2. **เว็บไซต์อ่อนไหว (ธนาคาร, บัญชีที่มีเงิน) ทำเอง** — อย่าให้ AI agent ล็อกอินหรือทำธุรกรรมแทนในเว็บพวกนี้
3. **ระวังลิงก์แปลก** — โดยเฉพาะลิงก์ที่ยาวมี query string ประหลาด อย่าให้ AI agent เปิดตามให้ทันที
4. **อัปเดตแอป/extension เป็นเวอร์ชันล่าสุดเสมอ** — ช่องโหว่ที่เจอมักถูกแพตช์ตามหลัง แต่ต้องอัปเดตถึงจะได้รับการป้องกัน
5. **อ่าน permission ที่ AI ขอก่อนกดอนุมัติ** — ถ้าขอสิทธิ์เกินความจำเป็นสำหรับงานที่จะทำ ให้สงสัยไว้ก่อน

สรุปคือ AI Browser Agent มีประโยชน์จริง ประหยัดเวลาได้เยอะ แต่ยังเป็นเทคโนโลยีที่ทั้งบริษัทผู้พัฒนาเองก็ยอมรับว่ายังไม่ปลอดภัย 100% — ใช้แบบรู้เท่าทันดีกว่าเชื่อมือทั้งหมดนะคะ
