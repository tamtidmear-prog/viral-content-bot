สวัสดีตอนเย็นค่ะ วันนี้มีข่าวใหญ่ 3 เรื่องที่น่าสนใจมากค่ะ มาดูกันเลยนะคะ 💡

📌 1. Gemini 3.5 Pro ใกล้เปิดตัวเต็มรูปแบบ — Context Window 2 ล้าน Token!

Google กำลังจะเปิดให้ใช้ Gemini 3.5 Pro แบบ General Availability (GA) ภายในสัปดาห์นี้ถึงสิ้นเดือนมิถุนายน 2026 ค่ะ จุดเด่นที่น่าตื่นเต้นที่สุดคือ context window ขนาด 2 ล้าน token ซึ่งเป็นขนาดใหญ่ที่สุดในบรรดา frontier model ที่ใช้งานได้จริงตอนนี้ค่ะ

เปรียบเทียบให้เห็นภาพง่ายๆ:
- Gemini 3.5 Flash: 1 ล้าน token
- Claude Opus 4.6: 1 ล้าน token  
- Gemini 3.5 Pro: 2 ล้าน token (มากกว่าเท่าตัว!)

สิ่งนี้หมายความว่าเราสามารถใส่เอกสารยาวๆ หนังสือทั้งเล่ม หรือ codebase ขนาดใหญ่เข้าไปในการสนทนาเดียวได้เลยค่ะ สำหรับนักพัฒนาและนักวิจัย นี่คือการเปลี่ยนแปลงครั้งใหญ่ที่จะทำให้การทำงานกับข้อมูลจำนวนมากง่ายขึ้นมากค่ะ

📌 2. Anthropic มูลค่าทะลุ $965 พันล้าน — ยื่น IPO แล้ว!

ข่าวใหญ่จากวงการ AI ค่ะ Anthropic บริษัทผู้สร้าง Claude ประกาศปิดรอบระดมทุนที่มูลค่า 965 พันล้านดอลลาร์ แซงหน้า OpenAI เป็นครั้งแรก และยังยื่นเอกสารเพื่อเข้าตลาดหลักทรัพย์ (IPO) แบบลับแล้วด้วยค่ะ

สิ่งที่น่าสนใจคือปัจจัยหลักที่ทำให้ Anthropic ขึ้นมาถึงจุดนี้ — Claude Code เครื่องมือ AI สำหรับเขียนโค้ดที่กำลังเปลี่ยนวิธีการทำงานของนักพัฒนาทั่วโลกค่ะ ตลาด AI coding กลายเป็นสมรภูมิหลักที่ทุกบริษัทใหญ่แข่งกันอย่างดุเดือด ไม่ว่าจะเป็น Google, Microsoft หรือ OpenAI ก็พยายามไล่ตามในส่วนนี้

สำหรับคนทั่วไป นี่หมายความว่า AI กำลังเปลี่ยนจาก "เครื่องมือตอบคำถาม" เป็น "เพื่อนร่วมงานที่ทำงานจริงได้" มากขึ้นทุกวันค่ะ

📌 3. SpaceX ซื้อ Cursor ในราคา $60 พันล้าน — AI Coding ร้อนแรงสุดๆ

Elon Musk's SpaceX ประกาศเข้าซื้อ Cursor ซึ่งเป็น AI code editor ที่ได้รับความนิยมสูงมากในหมู่นักพัฒนาด้วยมูลค่า 60 พันล้านดอลลาร์ค่ะ

Cursor เป็นเครื่องมือที่ช่วยนักพัฒนาเขียนโค้ดด้วย AI แบบ real-time ซึ่งเป็นคู่แข่งโดยตรงกับ Claude Code ของ Anthropic และ Codex ของ OpenAI การที่ SpaceX เข้ามาซื้อแสดงให้เห็นว่า AI coding ไม่ใช่แค่เทรนด์อีกต่อไป แต่เป็นโครงสร้างพื้นฐานที่สำคัญขนาดที่บริษัทระดับ SpaceX ยอมลงทุนมหาศาลค่ะ

สำหรับนักพัฒนาไทย สิ่งที่ควรจับตาคือ เครื่องมือเหล่านี้กำลังทำให้การเขียนโค้ดง่ายขึ้นและเร็วขึ้นมาก คนที่เรียนรู้การใช้ AI ช่วยเขียนโค้ดตอนนี้จะมีข้อได้เปรียบอย่างมากในตลาดแรงงานค่ะ
