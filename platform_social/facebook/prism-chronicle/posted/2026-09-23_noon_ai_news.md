⚡ สงครามราคา AI ปะทุ — 90 นาทีที่ Anthropic กับ OpenAI แข่งกันลดราคาโมเดลเรือธง

22 กันยายน 2026 เกิดเหตุการณ์ที่ไม่ค่อยเห็นบ่อย ๆ ในวงการ AI: สองบริษัทใหญ่ที่สุดของโลกปล่อยโมเดลใหม่ห่างกันแค่ประมาณ 90 นาที ทั้งคู่มาพร้อมกับราคาที่ถูกลงชัดเจน วันนี้ Prism พาไปดูว่าเกิดอะไรขึ้นจริง ๆ พร้อมตัวเลขตรงจากแหล่งข่าวหลัก

🟣 ก้าวแรก: Claude Opus 5.5

Anthropic เปิดตัว Claude Opus 5.5 เป็นโมเดลแรกในตระกูล 5.5 พร้อมใช้งานทันทีวันเดียวกัน

💰 ราคาต่อ 1 ล้าน token (เทียบ Opus 5):
- Input: $4 (จาก $5, -20%)
- Output: $20 (จาก $25, -20%)
- Cache read: $0.20 (จาก $0.50, -60%)
- งานทั่วไปที่ใช้จริง Anthropic บอกว่าประหยัดได้ถึง 40% เพราะยังใช้ output token น้อยลง 20-25% ด้วย

📊 ประสิทธิภาพ: Anthropic ระบุว่า Opus 5.5 ทำงานได้ใกล้เคียง Claude Fable 5.1 ในงานส่วนใหญ่ แต่นำหน้าในงาน agentic coding และ computer use ตามผล benchmark ที่เปิดเผย เช่น
- Terminal-Bench 4.0: Opus 5.5 ได้ 66.4% เทียบกับ Fable 5.1 ที่ 55.8%
- GDPval-AA v2.1: Opus 5.5 ได้ 1,846 Elo เทียบกับ Fable 5.1 ที่ 1,735 Elo
(ตัวเลขเหล่านี้เป็นผลทดสอบที่ Anthropic เผยแพร่เอง ยังไม่มีการทดสอบอิสระจากบุคคลที่สามมายืนยันซ้ำ)

🛡️ ด้านความปลอดภัย Anthropic บอกว่า Opus 5.5 ทำคะแนนดีที่สุดในบรรดาโมเดลที่เคยผ่าน automated behavioral audit ของบริษัท และพยายามฝ่าขอบเขตการทำงานที่กำหนดไว้ (boundary circumvention) น้อยลงราว 85% เทียบกับ Opus 5

ลูกค้าจริงพูดถึงด้วย — Yashodha Bhavnani (VP AI Products, Box): "ใช้ token น้อยลงหนึ่งในสาม คำตอบกระชับขึ้น 40% โดยไม่เสียความแม่นยำ" ส่วน Mario Rodriguez (CPO, GitHub) บอกว่าใน VS Code โมเดลนี้แก้ terminal task ได้มากกว่า Opus 5 ด้วยขั้นตอนน้อยกว่าครึ่งหนึ่ง

🟢 ก้าวที่สอง: OpenAI ตอบโต้ใน 90 นาที

ไม่ทันไร OpenAI ก็ปล่อย GPT-6 Sol และ GPT-6 Luna ออกมาแทบจะทันที ทั้งคู่ต่อยอดจากเทคนิคเบื้องหลัง GPT-6 Astra (โมเดลเรือธงที่ปล่อยก่อนหน้านี้ในเดือนเดียวกัน) มาไว้ในเวอร์ชันที่เร็วและถูกกว่า

💰 ราคา: OpenAI ลดราคา API ของ Sol และ Luna ลง 50% เทียบกับราคาโปรโมชั่นของ GPT-5.6 รุ่นก่อนหน้า
- GPT-6 Sol (เน้นงานโค้ดและ agent): $2 ต่อล้าน input token / $10 ต่อล้าน output token
- GPT-6 Luna (เน้นงานปริมาณมาก เช่น สรุปเนื้อหา): $0.10 ต่อล้าน input token / $0.50 ต่อล้าน output token
- Cache read ถูกลงถึง 90%

OpenAI บอกว่าโมเดลทั้งสองฝึกด้วยเทคนิคใกล้เคียง GPT-6 Astra ทำให้ได้ความสามารถด้านงานอาชีพ ความแม่นยำ การเขียนโค้ด การใช้คอมพิวเตอร์แทนคน และ alignment ติดมาในราคาที่ถูกลงมาก ใช้งานได้ใน ChatGPT Work และ Codex (Plus/Pro/Business/Enterprise/Edu) ส่วนผู้ใช้แผนฟรีและ Go เข้าถึง GPT-6 Luna ผ่านแอปเดสก์ท็อปได้เช่นกัน

ข้อสังเกต: สองบริษัทไม่ได้เทียบโมเดลกันตรง ๆ — Anthropic เทียบ Opus 5.5 กับ Fable 5.1 ของตัวเอง ส่วน OpenAI เทียบ Sol กับ Fable 5 ของคู่แข่งเท่านั้น ยังไม่มีบุคคลที่สามทดสอบเทียบ Opus 5.5 กับ GPT-6 Sol/Luna ตรง ๆ

📌 สรุปสำหรับคนทั่วไป: ไม่ว่าใคร "ชนะ" ผลลัพธ์ที่คนใช้จริงได้คือ AI คุณภาพสูงราคาถูกลงเรื่อย ๆ ทั้งนักพัฒนาที่จ่ายผ่าน API และคนทั่วไปที่ใช้แอปฟรี

🔍 อีกข่าวเดียวกันวัน: OpenAI เปิดทางให้คนนอกตรวจสอบความปลอดภัยตั้งแต่ตอนฝึกโมเดล

วันเดียวกันนี้ OpenAI ยังประกาศแผนเปลี่ยนวิธีตรวจสอบความปลอดภัยของโมเดล — จากเดิมที่ให้ทีมภายนอกเข้ามาประเมินความสามารถและความเสี่ยงเฉพาะช่วงก่อนปล่อยโมเดล เปลี่ยนเป็นเปิดให้องค์กรอิสระเข้าร่วมประเมินตั้งแต่ช่วงการฝึก (training) การทดสอบ (evaluation) ไปจนถึงช่วงปล่อยใช้งานจริง (deployment)

OpenAI ระบุ 4 พื้นที่หลักที่จะเปิดให้ตรวจสอบจากภายนอก:
1. การประเมิน safety case ตลอดทั้งกระบวนการฝึกและใช้งาน
2. การตรวจสอบมาตรการป้องกัน (critical safeguards) ที่สำคัญ
3. การประเมินความสามารถของโมเดลตามกรอบ Preparedness Framework ของบริษัทเอง
4. การสอบสวนอิสระกรณีโมเดลทำงานคลาดเคลื่อนจากที่ตั้งใจ (misalignment incidents)

หลักการที่ต้องการ: ความเป็นอิสระที่แท้จริง ความเข้มงวดทางวิทยาศาสตร์ มาตรการความปลอดภัยรัดกุม และความรับผิดชอบชัดเจนของแต่ละฝ่าย ขณะนี้กำลังคุยกับองค์กรอย่าง METR และ Redwood Research แต่ยังไม่ประกาศพาร์ตเนอร์อย่างเป็นทางการ

💭 มุมมอง Prism

สองข่าวนี้เกิดวันเดียวกันแต่สะท้อนคนละด้านของอุตสาหกรรม AI — ด้านหนึ่งคือการแข่งขันราคา/ความเร็วที่ดุเดือด จนโมเดลใหม่ออกห่างกันแค่ชั่วโมงเดียว อีกด้านคือความพยายามทำให้กระบวนการพัฒนา AI ตรวจสอบได้มากขึ้น ไม่ใช่แค่ตรวจตอนจบแล้วค่อยประกาศ

ความเร็วกับความปลอดภัยมักถูกมองว่าแข่งกันเอง การที่ OpenAI เปิดให้คนนอกเข้ามาดูตั้งแต่ช่วงฝึกโมเดล จึงเป็นทิศทางที่น่าจับตา — ต้องดูต่อว่าองค์กรอิสระจะได้อำนาจตรวจสอบมากแค่ไหน และผลตรวจจะเปิดเผยต่อสาธารณะแบบไหน

สำหรับคนใช้ AI ทำงานทุกวัน สิ่งที่จับต้องได้ที่สุดตอนนี้คือราคาที่ถูกลงจริง — ใครใช้ API หรือแผนเสียเงินอยู่ ลองเช็คหน้าราคาล่าสุดของทั้งสองเจ้าดู อาจประหยัดได้มากกว่าที่คิด
