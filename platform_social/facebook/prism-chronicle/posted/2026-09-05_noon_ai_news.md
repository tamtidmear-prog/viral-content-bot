🖥️ 1) NVIDIA เปิดตัว PAIR — เครื่องมือฟรีรวมพลัง GPU ในบ้านทำ AI

NVIDIA ประกาศเปิดตัว Personal AI Router (PAIR) เมื่อ 3 กันยายน 2026 ที่งาน IFA 2026 เป็นซอฟต์แวร์โอเพนซอร์สฟรี (สัญญาอนุญาต Apache 2.0) ที่ทำหน้าที่เป็น "ตัวจัดสรรงาน" — ค้นหาเครื่องคอมพิวเตอร์ที่มี GPU รองรับในเครือข่ายบ้านเดียวกันโดยอัตโนมัติ (ผ่านเทคโนโลยี mDNS) แล้วกระจายงานประมวลผล AI ไปยังเครื่องที่ว่างอยู่ ไม่ต้องแก้โค้ด agent เดิมเลย เพราะ PAIR ทำตัวเป็นตัวแทนหน้าตาเหมือน Ollama หรือ LM Studio ที่หลายคนใช้อยู่แล้ว

ฮาร์ดแวร์ที่รองรับตอนนี้คือการ์ดจอ NVIDIA GeForce RTX ซีรีส์ 20 ขึ้นไป, RTX PRO รุ่นเวิร์กสเตชัน, DGX Spark และเครื่อง Apple ที่ใช้ชิป M4 ขึ้นไป ใช้ได้ทั้ง Windows, macOS และ Linux

ตัวเลขที่น่าสนใจจากการทดลองจริงของ NVIDIA เอง — งานที่ให้ AI agent ย่อย 5 ตัวทำพร้อมกัน (รันบนโมเดล Qwen 3.6 35B A3B) ถ้าใช้โน้ตบุ๊ก RTX Spark เครื่องเดียวใช้เวลาเฉลี่ย 18 นาที แต่ถ้าใช้ PAIR รวมพลัง 3 เครื่อง (RTX Spark + DGX Spark + RTX 5090) เหลือเฉลี่ยแค่ 8 นาที 48 วินาที — ทาง NVIDIA เองก็บอกตรงๆ ว่านี่เป็นการสาธิตเฉพาะชุดอุปกรณ์นี้ ไม่ใช่ผลทดสอบมาตรฐานทั่วไปหรือคำสัญญาว่าจะเร็วขึ้นเป็นเส้นตรงเสมอไป

**ใช้ประโยชน์ยังไง:** ใครมีคอมหลายเครื่องที่มีการ์ดจอ NVIDIA อยู่แล้วในบ้าน (เช่น เครื่องเล่นเกมกับเครื่องทำงาน) ลองโหลด PAIR มาใช้ฟรีได้เลยที่หน้าเว็บ NVIDIA — เหมาะกับคนที่รัน AI agent หลายตัวพร้อมกันแล้วรู้สึกว่าเครื่องเดียวช้าเกินไป

🏆 2) Qwen3.8-Max-0902 จากจีน ขึ้นแท่นอันดับ 1 สนามทดสอบ OSWorld-Verified

Alibaba ปล่อยอัปเดตโมเดล Qwen3.8-Max-0902 เมื่อ 2 กันยายน 2026 (ต่อยอดจาก Qwen3.8-Max ตัวเต็มที่เปิดตัวไปเมื่อ 3 สิงหาคม 2026) เน้นพัฒนาความสามารถด้านเขียนโค้ดและงาน agent โดยเฉพาะ

ผลคือทำให้ Qwen3.8-Max ขึ้นเป็นอันดับ 1 บนตาราง OSWorld-Verified ซึ่งเป็นสนามทดสอบที่วัดว่า AI agent ควบคุมคอมพิวเตอร์จริงได้แม่นยำแค่ไหน (คลิกเมนู กรอกฟอร์ม ทำงานหลายขั้นตอนต่อเนื่องบนหน้าจอจริง) ด้วยคะแนน 86.1 แซงหน้า Claude Fable 5 ที่ทำได้ 85.0, GPT-5.6 Sol Max ที่ 83.2 และ Gemini 3.1 Pro ที่ 76.2

ด้านสเปก Qwen3.8-Max เป็นโมเดลแบบ mixture-of-experts ขนาด 2.4 ล้านล้านพารามิเตอร์ (ใช้งานจริงราว 9.5 หมื่นล้านพารามิเตอร์ต่อครั้ง) รองรับ context window ยาวถึง 1 ล้าน token ราคาผ่าน API อยู่ที่ 2 ดอลลาร์ต่อล้าน token ฝั่ง input และ 6 ดอลลาร์ต่อล้าน token ฝั่ง output ที่น่าสนใจคือ Alibaba ประกาศว่าจะเปิด open-weight ให้ทั้ง Qwen3.8-Max และรุ่นเล็ก Qwen3.8-27B ด้วย ซึ่งเป็นครั้งแรกที่ Alibaba เปิด weight ให้โมเดลระดับ Max ของตัวเอง

**ใช้ประโยชน์ยังไง:** ถ้ากำลังมองหาโมเดลไว้ทำ AI agent ควบคุมหน้าจอคอมพิวเตอร์ (เช่น ทำงานอัตโนมัติซ้ำๆ บนเว็บ) Qwen3.8-Max-0902 เป็นตัวเลือกที่คุ้มค่าน่าจับตา โดยเฉพาะเมื่อเปิด open-weight จริงจะยิ่งเข้าถึงง่ายกว่าโมเดลปิดของค่ายอื่น

📈 3) ธุรกิจโฆษณา ChatGPT ทะลุรายได้ 1 พันล้านดอลลาร์ต่อปี ในเวลาไม่ถึง 200 วัน

OpenAI ประกาศเมื่อ 31 สิงหาคม 2026 ว่าธุรกิจโฆษณาบน ChatGPT (ChatGPT Ads) มาถึงจุดที่มี annualized revenue run rate หรือรายได้ที่คาดการณ์ทั้งปีจากอัตราปัจจุบัน แตะ 1 พันล้านดอลลาร์สหรัฐแล้ว นับจากวันที่เริ่มทดสอบเปิดให้ผู้ใช้ทั่วไปในสหรัฐฯ เมื่อ 9 กุมภาพันธ์ 2026 ใช้เวลาไม่ถึง 200 วันเท่านั้น (ตัวเลขนี้คือการประมาณการรายได้ทั้งปีจากอัตราปัจจุบัน ไม่ใช่รายได้จริงสะสมที่เกิน 1 พันล้านดอลลาร์แล้ว)

พร้อมกันนี้ OpenAI เปิดระบบซื้อโฆษณาแบบ self-serve ให้นักการตลาดในอินเดีย ยุโรป ตะวันออกกลาง และแอฟริกาเหนือ เพิ่มเติมจากเดิมที่ให้บริการอยู่แล้วกว่า 40 ประเทศทั่วโลก ปัจจุบันมีผู้ลงโฆษณาระดับหมื่นรายบนแพลตฟอร์ม โดย OpenAI ย้ำจุดยืนว่าโฆษณาจะถูกแยกให้เห็นชัดเจนจากคำตอบของ ChatGPT เสมอ ไม่มีผลต่อเนื้อหาคำตอบ และผู้ลงโฆษณาจะไม่สามารถเข้าถึงบทสนทนาส่วนตัวของผู้ใช้ได้

**ใช้ประโยชน์ยังไง:** สำหรับคนทำธุรกิจหรือสายการตลาด นี่คือสัญญาณว่าช่องทางโฆษณาบน AI chatbot กำลังโตเร็วและเริ่มเปิดกว้างขึ้นเรื่อยๆ อาจเป็นจังหวะดีที่จะเริ่มศึกษาว่าธุรกิจของตัวเองเข้าไปลงโฆษณาบน ChatGPT ได้หรือยัง
