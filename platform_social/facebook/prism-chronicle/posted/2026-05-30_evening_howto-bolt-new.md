# Draft: วิธีใช้ AI สร้างเว็บไซต์และ deploy ฟรีใน 5 นาที

**Pillar:** 3 (How-To)
**Date:** 2026-05-30 เย็น
**Status:** draft

---

🌐 มีเว็บไซต์เป็นของตัวเองโดยไม่ต้องรู้โค้ดสักบรรทัด — เป็นไปได้แล้วในปี 2026

ผมทดสอบมาแล้ว — ใช้เวลาไม่ถึง 5 นาที

━━━━━━━━━━

🤔 ก่อนอื่น — ทำไมต้องมีเว็บไซต์?

เพราะโซเชียลมีเดียไม่ใช่ของคุณ
Facebook ปิด? เพจหาย Instagram เปลี่ยน algorithm? Reach ตก

แต่เว็บไซต์ของคุณ — ไม่มีใครมาเปลี่ยน algorithm ได้

Portfolio, แคตตาล็อกสินค้า, resume ออนไลน์, บล็อกส่วนตัว
สิ่งเหล่านี้ควรอยู่บนเว็บที่คุณเป็นเจ้าของ

━━━━━━━━━━

🛠️ เครื่องมือที่ใช้: Bolt.new

bolt.new คือ AI ที่สร้างเว็บไซต์ให้จากคำพูด
บอกมันว่าอยากได้อะไร → มันสร้างให้เลย — ทั้ง code, design, ทุกอย่าง
แล้ว deploy ให้ด้วย ได้ URL ฟรีทันที

ไม่ต้องติดตั้งโปรแกรม ไม่ต้องรู้ภาษา code
รันบน browser เลย

━━━━━━━━━━

📋 ขั้นตอน 5 ขั้น (ง่ายมาก)

**ขั้น 1 — เปิด bolt.new**
ไปที่ bolt.new → Sign up ด้วย Google ฟรี
ได้ quota ฟรีประมาณ 150,000 tokens ต่อวัน — เพียงพอสร้างเว็บได้หลายหน้า

**ขั้น 2 — บอก AI ว่าอยากได้อะไร**
พิมคำอธิบายในช่องแชท เช่น:
"สร้างเว็บ portfolio สำหรับช่างภาพ มีหน้าแสดงผลงาน หน้า about me และหน้า contact"

ยิ่งละเอียด ยิ่งได้ผลดี — บอก style, สี, จำนวนหน้า ได้เลย

**ขั้น 3 — รอ AI สร้าง (~30 วินาที)**
AI เขียน code ให้ดูเรียลไทม์ พร้อม preview ด้านขวา
เห็นหน้าเว็บปรากฏขึ้นมาตรงหน้าเลย

**ขั้น 4 — แก้ไขด้วยการพิมเพิ่ม**
ไม่ชอบสีตรงไหน? พิมบอก: "เปลี่ยนสีพื้นหลังเป็นโทนครีม"
อยากเพิ่มส่วน? พิมบอก: "เพิ่มหน้า FAQ ด้านล่าง"
ไม่ต้องแตะ code สักบรรทัด

**ขั้น 5 — Deploy กด 1 ปุ่ม**
กด Deploy → ได้ URL บน bolt.host ฟรีทันที
เช่น: yourproject.bolt.host
แชร์ได้เลย ใครก็เปิดได้จากทั่วโลก

━━━━━━━━━━

💡 ตัวอย่าง prompt ที่ใช้ได้จริง

"สร้างเว็บแคตตาล็อกสินค้าเบเกอรี่ มีรูปสินค้า ราคา และปุ่ม Line สั่งซื้อ โทนสีพาสเทล"

"สร้าง resume ออนไลน์ภาษาไทย มีส่วน ประสบการณ์ ทักษะ และการศึกษา ดีไซน์ minimal"

"สร้างเว็บ landing page โปรโมทคอร์สออนไลน์ มีส่วน testimonial และ pricing"

━━━━━━━━━━

⚠️ ข้อจำกัดที่ควรรู้

- URL ฟรี (.bolt.host) — ถ้าอยากใช้ domain ของตัวเองต้องอัปเกรด
- Free quota มีจำกัด 150k tokens/วัน — แต่เพียงพอสำหรับสร้าง + ทดสอบ
- เหมาะสำหรับเว็บ static, portfolio, landing page — ไม่ใช่ระบบ e-commerce ขนาดใหญ่

━━━━━━━━━━
