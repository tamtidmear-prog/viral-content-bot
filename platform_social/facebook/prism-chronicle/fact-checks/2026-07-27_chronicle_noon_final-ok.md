## 🟡 2 จุดที่เจอในภาพ — ควรแก้ ไม่ใช่ blocker

### #1 — คำว่า `Layer` ขึ้นในภาพจริง **(ผมเคยตรวจผิด ขอแก้คำ)**

```
ในภาพ (แถบขวาบน):  กฎเหล็กของ Prism: "เช็ค Layer สูงสุดเท่าที่ทำได้"
```

**ในไฟล์ fact-check รอบแรก ผมเขียนว่า** *"คำว่า `layer` ปรากฏเฉพาะใน infographic source (ไม่ขึ้นโพสต์)"*
**ผิดครับ — มันขึ้นภาพ** และภาพคือสิ่งที่คนเห็นก่อนอ่านแคปชั่นด้วยซ้ำ

และนี่คือจุดที่ **Codex เตือนไว้ (#11) แต่ผมกรองทิ้ง** เพราะคิดว่า `infographic_source` เป็นไฟล์ input ที่ไม่เผยแพร่
— ตัวไฟล์ไม่เผยแพร่จริง แต่ **ข้อความในนั้นถูกยกไปขึ้นภาพ** ผมแยกสองอย่างนี้ไม่ออกตอนกรอง
**Codex ถูก ผมผิด** ขอบันทึกไว้ตรงนี้

```
เสนอแก้ (ถ้ามีเวลา regen):  "เช็ค Layer สูงสุดเท่าที่ทำได้"
                        →  "เช็คระดับสูงสุดเท่าที่ทำได้"
```

ทั้งภาพใช้คำว่า "ระดับ" ตลอด มีแต่บรรทัดนี้ที่ใช้ `Layer` — สลับคำเดียวก็สม่ำเสมอทั้งภาพ
**ไม่ถึงขั้นต้องเลื่อนโพส** เพราะคนไทยส่วนใหญ่อ่าน "Layer" ออก และมีคำว่า "ระดับ" อธิบายล้อมรอบอยู่แล้ว

### #2 — "สูงสุดเท่าที่ทำได้" (ภาพ) vs "ขยับขึ้นอีกระดับหนึ่ง" (draft)

จุดนี้ Codex ทักไว้ใน Addendum-1 #A1 และยังไม่ได้แก้ — ภาพกับแคปชั่นแนะนำคนละท่า:

```
ภาพ:    เช็ค Layer สูงสุดเท่าที่ทำได้ · อย่าหยุดแค่ระดับ 1-3
draft:  ลองขยับขึ้นไปดูอีกระดับหนึ่ง · ไม่จำเป็นต้องไปถึงระดับ 5 ทุกครั้ง
```

**ไม่ขัดกันถึงขั้นสอนผิด** (ทั้งคู่บอกว่าอย่าหยุดที่ระดับต่ำ) แต่คนอ่านละเอียดจะสังเกตว่าน้ำเสียงต่างกัน
ท่าของ draft ใช้ได้จริงกว่าในชีวิตประจำวัน — ถ้า regen รอบหน้าปรับภาพให้ตามก็ดี
