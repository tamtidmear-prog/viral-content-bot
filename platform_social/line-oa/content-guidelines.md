# LINE OA — Platform Content Guidelines

> Direct messaging + CRM — สื่อสารตรงกับ followers

## ขอบเขต Platform

### ✅ เนื้อหาที่เหมาะกับ LINE OA
- Broadcast ข่าวสำคัญ — เฉพาะเรื่องที่คุ้มค่าให้ push notification
- Rich Message — สรุป content สวยๆ พร้อม link
- สรุปประจำสัปดาห์ — รวม content ดีๆ จากทุก platform
- Exclusive content — เนื้อหาพิเศษเฉพาะ LINE
- Auto-reply — FAQ, ทักทาย

### ❌ เนื้อหาที่ไม่เหมาะ
- Broadcast ถี่เกินไป (ผู้ใช้จะ block)
- เนื้อหาที่ไม่มี value สำหรับผู้รับ
- ข่าวการเมือง / ศาสนา
- Spam / โฆษณาไม่เกี่ยวข้อง
- ข้อความยาวไม่มี structure

## ความถี่ที่เหมาะสม
- Broadcast: สูงสุด 2-3 ครั้ง/สัปดาห์
- ถ้า broadcast เกิน → ผู้ใช้ block สูง
- ทุก broadcast ต้องมีคุณค่าชัดเจน

## Tone & Voice
- ภาษา: ไทย สุภาพ เป็นมิตร
- Tone: personal, direct, helpful
- สั้นกระชับ — คนอ่านบน mobile
- Rich Message ดีกว่า text ยาว

## กฎเหล็ก
1. ทุก broadcast ต้องได้รับอนุมัติจาก Master J
2. ห้าม broadcast เกิน 3 ครั้ง/สัปดาห์
3. ทุก message ต้องมี value ชัดเจน
4. Auto-reply ต้อง Master J อนุมัติ template ก่อน
