Viral Content Bot — Flow Chart

1
Master J

พิมพ์หัวข้อ

พิมพ์หัวข้อที่ต้องการโพส เช่น "เกมส์ใหม่น่าเล่น"
+ เลือก Facebook Page ที่จะโพส
+ แนบรูปภาพ (ถ้ามี)

CLI หรือ Web UI
2
brain.ts Groq Cloud API ~1-2 วินาที

AI วิเคราะห์ + สร้าง Content

จับคู่ keyword กับ template (gaming/finance/lifestyle)
→ ส่งไป Groq AI (llama-3.3-70b)
→ ได้ caption + hashtags + image prompt กลับมา

📄 brief.json   📄 caption.txt   📄 hashtags.txt   📄 image-prompt.txt
3
image.ts Gemini API ~2-3 วินาที

สร้างรูปภาพ (ไม่บังคับ)

เอา image prompt → ส่ง AI สร้างรูป
ถ้าไม่มี API key หรือ quota เต็ม → ใช้ placeholder
หรือ Master J แนบรูปเอง → ข้ามขั้นนี้

🖼️ image.png หรือ 📄 image-placeholder.txt
4
facebook.ts Facebook Graph API ~2-3 วินาที

โพสขึ้น Facebook Page

ไม่มีรูป: POST /{page_id}/feed + caption
1 รูป: POST /{page_id}/photos + รูป + caption
หลายรูป: upload ทีละรูป (unpublished) → รวมเป็นโพสเดียว

📄 post-result.json → URL ของโพส
5
logger.ts Local disk

บันทึก Log ทั้งหมด

รวมทุก step ไว้ในไฟล์เดียว ดูย้อนหลังได้

📄 full-log.json (topic + caption + hashtags + ผลโพส + เวลา)
✅
Facebook Page

โพสขึ้นเพจสำเร็จ!

คนทั่วไปเห็นโพสบนเพจ Facebook ทันที
Master J ได้ลิงก์โพสกลับมา

รวมทั้งหมด ~5 วินาที ตั้งแต่กดจนโพสขึ้นเพจ
